> Ren'Py ゲーム向け **Translator3000**（ストック版 `1.45.11`）を、読みやすく開発を続けられる形で再構築したソースです。配布されていた `Translator3000.rpa` から復元し、難読化を完全に解除して、ゲームに入れるだけで使える単一の `Translator3000.rpa` に再びパッケージ化できます。

Translator3000 は Ren'Py ゲームをプレイ中に自動翻訳します。会話とメニューを取得し、翻訳サービスへ送り、結果をゲームごとのデータベースにキャッシュして、原文の代わりに訳文を表示します。このリポジトリが存在するのは、Translator3000 の現行（v3）ソースが公開されておらず、古い公開 v2 ソースは何年も前に陳腐化しているためです。ここでは最新のストックビルドをクリーンなソースコードへ逆行復元し、コミュニティが研究・修正し、その上に新機能を開発できるようにしています。

---

## ✨ 機能

### 翻訳

- プレイ中の会話と選択メニューの**リアルタイム翻訳**。
- **4 つの動作モード**：オフ、事前スキャン（ゲーム全体を事前に翻訳）、DB のみ（データベースにある訳文だけを表示）、リアルタイム + DB。
- **多数の組み込みサービス**：Google（GTX / client5 / RPC）、Bing、DeepL（公式 API、RPC、Selenium）、Yandex、Reverso、LingvaNex。
- **ゲームごとの翻訳データベース**：翻訳済みの行はすべてキャッシュされ、シーンを再生しても新しいリクエストは不要です。クラウドに用意されたデータベースがあれば再利用します。
- 翻訳時の文分割、リクエスト頻度制御、プロキシと Tor のサポート、データベースからの変数置換。

### ゲーム内パネル

- ゲーム内で開く設定パネル。翻訳サービス、言語の方向、動作モードを制御できます。
- フォントと表示テキストの設定（サイズ、色、縁取り、レイヤー）、翻訳先言語に応じたフォントの自動選択。
- ゲーム変数エディタ、テキストエディタ、カスタムキー組み合わせ、カラーテーマ、ドラッグ・リサイズ可能な翻訳ウィンドウ。
- 通知フィード、統計、翻訳キャッシュの管理、データベースのバックアップ。

### インターフェース言語

- インターフェースは**英語（デフォルト）**、ロシア語、ベトナム語、チュヴァシ語、トルコ語に対応。
- ベトナム語は今回の再構築で新しく追加され、文字列を完全にカバーしています。

### 互換性

- 同じアーカイブで **Ren'Py 7（Python 2）** と **Ren'Py 8（Python 3）** のゲームをサポート — `py2` / `py3` のデュアルモジュールツリーをビルド時にパックします。
- **単一の `.rpa` ファイル**として提供：ゲームの `game` フォルダにコピーするだけで動作し、他のファイルは不要です。

## 🚀 インストール

1. パッケージをビルド（[ビルド](#-ビルド)を参照）するか、ビルド済みの `build/Translator3000.rpa` を使用します。
2. `Translator3000.rpa` を Ren'Py ゲームの `game` フォルダにコピーします。
3. ゲームを起動し、ホットキーで Translator3000 パネルを開いて、翻訳サービスと動作モードを設定します。

> 個別の `.py` / `.rpy` ファイルをゲームにコピーしないでください。個別ファイルは RPA 内のファイルより優先されます。Ren'Py は `game` フォルダ内のすべての `.rpa` を自動で読み込みます。

---

## 📖 使い方

1. ゲーム内で Translator3000 パネルを開きます。
2. **翻訳サービス**を選び、**原文 / 訳文の言語**を設定します。
3. 動作モードを選びます：
   - **事前スキャン** — ゲーム全体を事前にデータベースへ翻訳（その後の体験が最良になります）。
   - **DB のみ** — データベースにある訳文だけを表示。
   - **リアルタイム + DB** — データベースを優先し、不足分をライブ翻訳。
   - **オフ** — 原文。
4. インターフェース言語を変えるには、パネルの言語ボタン（`EN` / `VI` / `RU` / …）を使います。初回起動時のデフォルトは英語です。

## 🔧 ビルド

要件：

- Python 3（`build.py` を実行し、`py3` モジュールツリーをパック）。
- Python 2.7 インタプリタ（`py2` モジュールツリーを `.tr3000py` にパック）。
- Ren'Py 7 のゲームまたは SDK の実行ファイル（`.rpy` を `.rpyc` にコンパイル）。

```text
python build.py --renpy7-exe "C:\path\to\RenPy7Game.exe" --python2 "C:\path\to\python27\python.exe"
```

出力：`build/Translator3000.rpa`（RPA-3.0）。

ビルドの仕組み：`.rpy` ファイルをステージングフォルダで Ren'Py 7 によりコンパイルし、`.py` モジュールをストック形式の `.tr3000py`（AST → pickle → base64 → zlib、元の `PyLoader` が期待する形式）にエンコードし、すべてをストック版とまったく同じランタイム配置で 1 つの RPA にパックします。

### リポジトリ構成

```text
src/
  000translator3000_main.rpy        メインスクリプト（GUI + コア、難読化解除済み）
  translations/                     インターフェース文字列（EN / VI / RU / CV / TR）
  _translator3000_main_modules/
    py2/_translator3000/*.py        Ren'Py 7 ゲーム用モジュール
    py3/_translator3000/*.py        Ren'Py 8 ゲーム用モジュール
  _translator3000_extra_modules/    同梱ライブラリ
  old_requests_module/  old_pkgutil_module/  uuid_py3_fix/  _extra_six.py
  Translator3000OtherFiles/         フォント、GUI 画像、変数パターン
tools/                              難読化解除と翻訳生成のツール
build.py                            パッケージビルダー
```

### ソースの再構築方法

ストックアーカイブを展開し、その `.rpyc` を unrpyc（作者が AST として保存した Python コードを読めるようパッチ済み）でデコンパイルし、`.tr3000py` モジュールを圧縮された AST pickle から Python ソースへデコードしました。続いて安全な静的畳み込みにより、作者が分割・算術難読化した文字列を通常のリテラルに戻しました（例：`__version__ = '1.45.11'`）。コメントと元の整形は性質上復元できません。動的難読化と Ren'Py により改名された識別子は、動作を保つためそのまま保持しています。

## 🤝 コントリビューション

Issue と pull request を歓迎します。

- バグ報告の際は、Ren'Py のバージョン、ゲーム名、動作モードと翻訳サービス、関連するログ / トレースバックの行を含めてください。
- Ren'Py ロジックは `src/000translator3000_main.rpy`、翻訳モジュールは対応する `py2` / `py3` ツリー、インターフェース文字列は `src/translations/` を編集し、`build.py` で再ビルドしてください。
- 共通コードに触れる場合は、Ren'Py 7 のゲームと Ren'Py 8 のゲームの少なくとも 1 つずつでテストしてください。
